# ECHO LADDER — Originality check (adversarial)

**Core mechanic under test (skin-free):** a *wagered* memory game where the **live market
mints a growing sequence** of price-authored notes (each new note = a real price reversal /
swing), plays it back, then the player must **reproduce it from memory in order**, and the bet
settles by **how deep into the sequence the player recalls correctly before a slip** (depth ×
swing-magnitude difficulty). I tried to disprove this is original by searching the *mechanic*
under many phrasings — not the made-up name.

## Method
Searched via web search across general Google-style results, with phrasings aimed at:
the live-price-authored angle, the Simon/memory-recall angle, the crypto/casino angle,
itch.io, and the Deriv/synthetic-index angle. (Chrome navigation was denied on the shared
gallery browser, so X/YouTube/app-store browsing was done through web search surfacing those
domains rather than logged-in sessions; results below reflect what surfaced.)

## Queries run & closest matches

1. **"memory sequence game where live stock price action creates the pattern to recall"**
   - Closest: Human Benchmark *Sequence Memory Test* (https://humanbenchmark.com/tests/sequence);
     ProProfs Pattern Memory (https://www.proprofsgames.com/pattern-memory/); an academic
     piece on "market memory / historical patterns"
     (https://veraspace.me/p/market-memory-learning-from-historical-patterns/).
   - Verdict: generic recall tests and *analysis* articles. None makes price action *author*
     a sequence to replay, and none is wagered.

2. **"Simon says memory game crypto trading bet recall sequence multiplier"**
   - Closest: Simon (game) — Wikipedia (https://en.wikipedia.org/wiki/Simon_(game));
     various free Simon clones (memozor, playbrain).
   - Verdict: classic Simon prior art (expected). No trading/price-authored or wagered variant
     found.

3. **"trading game repeat the price melody pattern each round bet how deep you remember"**
   - Closest: **Candlestick Patterns Memory Game** (https://gamesfortraders.com/memory-game/) —
     a flashcard pairing pattern *names* to drawings; an agent-based "Speculation Game" arXiv
     paper where agents "reference the last M digits of history."
   - Verdict: the candlestick memory game is a static educational matching game (no live feed,
     no replay-in-order, no wager-on-depth). The arXiv paper is academic theory, not a game.

4. **"crash gambling game memory recall mechanic instead of cashout itch.io"**
   - Closest: itch.io gambling tag, CASINO CASUALTY (https://glitchedlizard.itch.io/casino-casualty),
     generic crash-game explainers.
   - Verdict: standard crash/casino fare. No memory-recall settlement found anywhere.

5. **"Deriv synthetic index game memorize price swings play back ladder rungs wager"**
   - Closest: Deriv's own synthetic-index product pages (Step/Crash-Boom/Volatility indices).
   - Verdict: confirms the *feed* fits Deriv, but no existing Deriv game uses a memory-recall core.

6. **'"memory" OR "Simon" betting game where sequence grows from real market reversals pivots'**
   - Closest: Simon clones again; a spread-betting "trading market reversals" strategy article.
   - Verdict: reversals appear only as a trading *strategy* topic, never as the generator of a
     memory sequence in a game.

## Closest existing thing (single best link)
**Candlestick Patterns Memory Game** — https://gamesfortraders.com/memory-game/ — the only hit
that combines "trading" + "memory game." It is a static name↔drawing matching flashcard with no
live price, no growing/replayed sequence, and no wager. Distant.

## Honest verdict: **ORIGINAL**

Generic memory/Simon games and generic crash/casino games both have heavy prior art — that is
acknowledged and unavoidable. But the **specific union** that defines ECHO LADDER is not found
in any shipped product:
- the sequence is **intrinsically minted by real market price reversals** (pivots → rungs),
- the difficulty/payout table is **written by realized volatility** (swing magnitude = note
  value),
- the sequence **grows by one market-authored note each round**, and
- the **bet settles on recall depth × difficulty** with a bank-or-push decision.

No existing game wagers on memorizing-and-replaying a *price-authored, live-extended* sequence.
The nearest neighbours are either (a) un-wagered abstract memory tests, (b) static trading
flashcards, or (c) crash/casino games with timing/cashout settlement — all structurally
different from a recall-depth settlement on a market-composed melody. Verdict stands: ORIGINAL.
(Residual risk lives only in the *family* of "Simon-like memory," which is mitigated by the
live-price authoring and wagered-depth settlement that no prior art combines.)
