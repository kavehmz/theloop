# Originality check — BALLAST

**Core mechanic under test (in plain words, not the brand name):**
A game where you stack/place weighted blocks along a beam balanced on a single fulcrum (a see-saw / scale), and the **live market price is the physical tipping force** — price velocity tilts the beam left/right, volatility hits it as quakes — and you **wager on how high you can build / how long you can keep it from toppling**, banking a height-based multiplier before it tips past the topple angle.

This is a CONSTRUCTION / BALANCE / TORQUE-PHYSICS mechanic, not a tile-pick climb (Towers) and not a scalar-rising-to-a-bust (Crash). I tried hard to disprove its originality below.

---

## Methodology
Adversarial: I searched multiple **paraphrases of the core mechanic** (balance beam, fulcrum, see-saw, teeter-totter, tilting scale, lever/torque, counterweight, topple) crossed with the betting/market layer (multiplier, wager, gambling, live price, volatility, trading), across Google web + the platforms each query surfaced (itch.io, Google Play, crypto-casino sites, Deriv, Medium, TradingView, Amazon/Etsy/Target retail). I noted the closest match for each and judged whether it shares the *core mechanic*.

> Tooling note: searches were run via the web-search tool (Google-backed, US results), which also surfaces itch.io / Google Play / crypto-casino / ProductHunt-style pages inline. I did **not** separately log into X/Reddit/YouTube/app-store apps for this run — the shared browser was permission-locked during this session, so I relied on web search that indexes those platforms. I flag this honestly: claims below cover what web search actually returned.

## Closest existing things, ranked

1. **Physics balance/stacking arcade games** — *TOPPLE*, *Totemori*, *Wobble Pole*, *Stack Toys: Balance Tower*. These share the *physical balance/topple* feel, but **none is driven by a live market feed and none has a real bet/multiplier**. They are toys, not trading games. (Closest on the *physics* axis.)
2. **Crypto "Tower" casino games** (Rainbet/Shuffle/Tower.bet/Roobet). Share the "stack-and-cash-out" *framing* word "tower", but are the explicitly-banned **tile-pick row-climb** — guess a safe cell, no physics, no balance, no live price. (Closest on the *casino-genre* axis, and explicitly disqualified by the brief — BALLAST is deliberately the opposite: continuous rigid-body balance, not cell-guessing.)
3. **Crash/Aviator** — shares only the optional cash-out-a-multiplier wrapper, which the brief flags as crowded. BALLAST's outcome is **not** a scalar rising to a hidden bust; it is decided by whether the player keeps a two-directional torque system in equilibrium via *spatial lever placement*. Different core.

## Verdict: **ORIGINAL**

I could not find any existing game that uses **live market price action as the physical tipping torque on a fulcrum/balance you actively counterweight by placing mass along a lever arm, wagering on structural survival/height.** The two ingredient-families each exist separately — (a) physics balance/stacking arcade toys, and (b) crypto stack/crash betting games — but their **combination, with real price velocity + volatility as the destabilizing forces and lever-arm placement as the player's decision, did not appear anywhere** I searched. It is mechanically distinct from the banned Towers (no tile-guess ladder) and from Crash (no scalar bust — you fail by losing balance, a state you defend). 

**Honesty caveats:** (1) I relied on web search indexing of the platforms rather than separate native logins to X/Reddit/YouTube/app stores this session, because the shared browser was permission-locked; a deeper itch.io/Steam crawl could surface an obscure physics-betting hybrid, though none appeared. (2) The *physics-balance genre itself* is well-trodden (caveat noted) — BALLAST's novelty is specifically the **live-market-as-torque + wager** binding, not the act of balancing per se.
