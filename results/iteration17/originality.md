# Originality check — FLUXYARD

**Core mechanic (skin-free, what I searched against):** a live price feed spawns a stream of market-tagged "items"; the player must *classify each item's regime in real time* (bull / chop / bear) and *route it to the matching chute* before the queue overflows; the bet is settled by *correct-sort throughput × accuracy multiplier* before overflow ends the round.

I searched to **disprove** originality across multiple phrasings of the mechanic (not the made-up name), spanning Google web, app stores, itch.io, Poki/CrazyGames, Steam, prediction/trading-game sites, and patents.

## Queries run (verbatim) + closest matches

1. `trading game sort items conveyor belt classify market regime bull bear chute`
   → Only real market-regime *trading articles* (kjtradingsystems, trademem.com, ScienceDirect, luxalgo). **No game.**
2. `crypto game sort parcels conveyor lanes real time before overflow throughput`
   → Industrial parcel-sortation systems + USPTO patents (StreamTech, AnyLogic, conveyor-singulator patents). **No game, no market.**
3. `sorting arcade game route items to bins before queue overflows skill classification itch.io`
   → Closest *genre cousin*: **Sortify** (marconathan, itch.io) — a fast fruit-into-bins sorter. itch.io `tag-sorting` / `tag-organizing` lists. https://marconathan.itch.io/sortify — casual, no market, no live data, no betting.
4. `stock market gamble game classify candle trend route lane payout throughput dopamine`
   → Candlestick-pattern *practice simulators* (gamesfortraders.com, tradinggame.com.au) + a gambling/trading academic paper (PMC). These are the **banned candlestick-clicker** family; none sort/triage a stream.
5. `Deriv synthetic indices game sorting triage conveyor regime classification`
   → Deriv's **Drift Switch Indices (DSI)** — a real Deriv *product* with Positive/Negative/Driftless regimes. https://deriv.com/markets/derived-indices/synthetic-indices — a market instrument, **not a game**; confirms the 3-regime framing is native to Deriv (strong fit), not a competitor.
6. `"sort the trend" OR "regime sorter" OR "market triage" game route signals lanes betting`
   → **Market Sort** (Poki / Google Play), Supermarket Sort, **Sorting Inc** (Steam app 3227640) — casual shelf/grocery sorters. https://poki.com/en/g/market-sort , https://store.steampowered.com/app/3227640/ — "Market" = grocery market, no finance, no live chart, no wager.
7. `conveyor belt sorting game live price chart bet real money trading youtube gameplay`
   → ChartGame, Trading Game (App Store/Play), Wall Street Survivor, Polymarket. Paper-trading sims + prediction markets. **None** have a sorting/triage loop.
8. `trading casino game classify each tick momentum sort lane miss penalty queue overflow novel`
   → Only quant microstructure literature (order-book queue imbalance, tick data). **No game.**

## Closest existing things (honest)
- **Sortify (itch.io)** and **Sorting Inc (Steam)** — share the *sort-fast-into-bins-before-failure* arcade skeleton, but have **no market, no live data, no regime classification, and no bet/payout**. They are pure casual puzzles. Closest by *form*, distant by *substance*.
- **Candlestick trading simulators** (Trading Game, gamesfortraders) — share the *read-the-tape* theme but are paper-trading "guess the next candle" tools (a banned genre). No sorting/triage throughput, no real-time conveyor.
- **Deriv Drift Switch Indices** — a market *product* whose 3 regimes my game classifies; not a game, so not a competitor. Confirms authentic Deriv fit.

## Verdict: **ORIGINAL**
No existing game fuses (a) a live price feed that *generates and labels* a stream of discrete items, (b) a *real-time per-item regime-classification + routing* decision, and (c) a *correct-sort throughput-before-overflow* betting settlement. The casual sorters lack the market and the wager; the trading games lack the sorting/triage loop (and are the banned candlestick family). The combination — market-driven classification throughput as a bet — appears nowhere in the searched space. The single closest existing thing by mechanic-form is **Sortify** (https://marconathan.itch.io/sortify), and it is a non-market casual fruit-sorter, not a copycat.
