# THREADLINE — adversarial originality check

**Core mechanic under test:** the player draws a *freehand corridor / ribbon of adjustable width* into near-future chart time; the live price must stay *contained inside that hand-drawn shape* as a sweep-line advances; thinner ribbon = higher multiplier; early-cut banks a partial. (i.e. you bet the **route** of price, scored by **containment of the realised path within a player-authored 2-D shape over time**.)

I tried to **disprove** originality by searching the mechanic (not my made-up name) across web, crypto-casino, app stores, itch.io, ProductHunt, X, Reddit and YouTube angles.

## Closest matches found (with links) and why each differs

1. **BC.GAME "Tap Trading"** — *closest commercial match.*
   https://www.prnewswire.com/news-releases/bcgame-launches-tap-trading-a-price-touch-multiplier-game-for-crypto-markets-302562737.html
   You **tap one green target block** on a right-hand grid; each block shows a pre-set multiplier + time window; if the live price curve **touches that block** before the timer, you win stake × multiplier.
   → This is a **grid / single-cell touch** bet — exactly the "GridGame" genre the brief names as the *anchor not to reproduce*. It has **no freehand drawing, no corridor, no adjustable-width risk dial, and no containment of the price *path* over time inside a player-drawn shape.** You pick a point; THREADLINE you draw a *route* and must stay *inside it the whole way*. Different core mechanic.

2. **Drawing price channels by hand** (technical-analysis technique) —
   https://www.dummies.com/article/business-careers-money/personal-finance/investing/general-investing/how-to-draw-trading-chart-channels-by-hand-205949/ ; https://www.morpher.com/blog/price-channels
   → An *analysis practice* (parallel trend lines), not a game, no wager, no live containment scoring, no payout. Conceptually adjacent (a "band" around price) but not a betting mechanic and not authored as a forward-time corridor bet.

3. **ChartGame / "Trading Game – Stock Simulator" / The Stock Market Game** —
   https://chartgame.com/ ; https://apps.apple.com/us/app/trading-game-stock-simulator/id1202332044 ; https://www.stockmarketgame.org/
   → Trading **simulators**: you buy/sell on real charts; some allow drawing trendlines for analysis. The wager is a buy/sell position, **not** "the price must trace the shape I drew." Different mechanic.

4. **Deriv "Stays Between / Goes Outside" barrier contract** —
   https://developers.deriv.com/docs/stays-between
   → A **static horizontal corridor** (fixed upper/lower barrier) for a fixed period. THREADLINE generalises this to a **freehand, time-varying, player-drawn** corridor whose **width is a continuous live multiplier dial** with an early-cut bank. My spec explicitly cites this as the contract THREADLINE *extends* — it is the conceptual ancestor, not the same game (no drawing, no shape, no per-tick path scoring of a curve).

5. **Crash games / Plinko / prediction markets (Polymarket) / "Tap-touch" multiplier games** —
   https://stake.com/casino/games/crash ; https://polymarket.com/
   → All bet a **scalar** (multiplier-before-crash, a slot path, an event outcome, up/down). None bet a hand-drawn 2-D path with containment. These are the saturated genres THREADLINE is deliberately built to avoid.

## Platforms checked & result
- **Google web** (10 distinct mechanic phrasings): no game where price must trace/stay-inside a *player-drawn* path/corridor.
- **Crypto-casino space**: closest = BC.GAME Tap Trading (grid touch) — different mechanic.
- **itch.io**: only generic gambling sims (Gamblers Table, Gambling Simulator) — no drawn-path price game.
- **ProductHunt / app stores**: route-drawing exists for *running maps* (DrawRun) and trading *simulators*; nothing combining drawn corridor + live price containment + wager.
- **X / Twitter** (logged in, Latest + Top): no results / only trend-line TA education content.
- **Reddit / YouTube** (via search intent): only price-channel TA and prediction-market discussion; no matching game.

## Verdict: **ORIGINAL**

Across every source I searched, no existing game uses THREADLINE's core mechanic: **wagering a freehand-drawn corridor/ribbon of player-controlled width into future time and scoring it by real-time containment of the realised price path, with the ribbon width as a continuous multiplier dial and an early-cut bank.** The nearest real product, BC.GAME Tap Trading, is a single-cell *touch* bet (the grid-game genre), not a drawn-route containment bet. Drawing-on-charts elsewhere is analysis, not a wager. The mechanic predicts the *route* of price, not a scalar outcome, and is not a reskin of Crash/Plinko/Mines/Dice/Limbo/Wheel/HiLo/Towers/candlestick-clicker/up-down.

*Honesty note:* I claim only the sources listed above. "ORIGINAL" means no near-identical game surfaced in these searches — not a guarantee none exists anywhere unindexed. The single closest adjacent product is BC.GAME Tap Trading (grid-touch), which is a genuinely different mechanic.
