# Originality check — SENTE

Goal: adversarially DISPROVE that "a board duel where the live market's realized price action
is the opponent's forced stone placements, settled by flank-captures + engaged-chain
connectivity" already exists. Searches run via live web search (multiple phrasings of the core
mechanic, never the made-up name), June 2026.

## Queries run

1. `trading game place stones grid price chart opponent board game market moves`
2. `betting game where market price places pieces on a board and player captures them`
   (search engine itself ran several follow-up variants: capture pieces board games, GambleFi
   betting, stock market board game patents)
3. `"price action" gomoku OR go OR othello live chart crypto game candles place pieces`
4. `play board game against the stock market AI candlestick grid capture flank game itch.io`
5. `pente custodial capture game live data feed opponent moves driven by real time price`
6. `crypto casino game grid cells price path connect chain multiplier longest connected payout`
7. `game where the market is your opponent makes moves on a board "stock market" chess OR go OR reversi versus price`
8. `bet on price bucket grid cells future candles trading game multiplier "grid trading game"`

## Closest matches found (with links)

- **Pente** — https://en.wikipedia.org/wiki/Pente — the abstract ancestor of the capture rule
  (custodial "sandwich" capture, 1977). Human vs human on a static board; no market, no betting,
  no forced moves, no connectivity payout. SENTE borrows the *capture idiom* the way card games
  borrow "tricks"; the opponent, the decision (scarce pre-placement vs a price-driven adversary)
  and the settlement (engaged-chain tier + capture bonus paid against a stake) exist nowhere in it.
- **Acquire / 18XX / stock-market board games** — https://www.topstep.com/blog/10-great-board-games-for-traders,
  https://patents.google.com/patent/US4934707A/en — tile/board games *themed* on markets; prices
  are resource tracks moved by cards/players. No live feed, the market never places pieces.
- **Cluster-pays / grid slots** — https://www.online-slot.co.uk/online-slots/grid-slots/ —
  "connected cluster pays" exists in slots, but as pure RNG symbol drops: no placement decision,
  no adversary, no captures, no market.
- **Shuffle Mines / Tower** — https://shuffle.com/games/originals/mines — grid casino games;
  reveal-tiles-with-multiplier, no opponent stones, no topology scoring, no chart.
- **ChartGame / trading simulators** — https://chartgame.com/ ,
  https://gamesfortraders.com/trading-simulator/ — historical-chart buy/sell practice; no board,
  no pieces, no capture.
- **Grid trading (the strategy / bots)** — https://quantpedia.com/a-primer-on-grid-trading-strategy/ —
  a real trading technique named "grid", but it is laddered limit orders, not a game, and shares
  only the word "grid".
- **itch.io stock-market tag sweep** — https://itch.io/games/tag-stock-market — sims, roguelikes,
  tycoons; the engine-summarized closest item (Market Mayhem, browser trading sim) has no board
  mechanics.
- **Pente Live (app)** — https://apps.apple.com/us/app/pente-live/id595426592 — online human
  matchmaking for Pente; "live" means realtime humans, not a data feed.

## What was NOT found

No game, in any of the above ecosystems (board-game databases, itch.io, crypto-casino
originals, app stores surfaced via these queries, patents), where:
- a live/realtime price feed generates the **opponent's forced placements** on a board
  (candle range → stones in price-bucket rows), and/or
- a bettor pre-places scarce pieces to **flank-capture** those market pieces (including
  pre-set ambushes the tape "walks into"), and/or
- settlement is an **engagement-gated largest-connected-chain tier plus per-capture bonus**
  paid against a stake.

Each of the three pillars exists separately (custodial capture: Pente; connected-cluster
payouts: grid slots; price-bucket grids: GridGame-style products). Their combination — and the
defining inversion that the chart IS the opponent's hand — was not found anywhere.

## Verdict

**ORIGINAL.** Closest ancestor is Pente (mechanic idiom only, 0 market/betting overlap);
closest fintech neighbours share only the grid visual, not the decision or the settlement.
Claimed scope: the queries listed above and the engines' own follow-up variants; I did not find,
on any result page inspected, a market-driven board-duel betting game.
